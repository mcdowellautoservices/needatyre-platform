# NeedATyre Complete Build Roadmap

## Included
- Next.js/Tailwind app
- Homepage, tyre results, booking and checkout pages
- Customer, fleet, garage, admin and emergency pages
- Mock vehicle lookup API
- Mock tyre catalogue API
- Mock booking API
- Branding and marketing pack
- Vercel/GitHub-ready project structure

## Production integrations still required
1. Vehicle lookup provider for UK registration search.
2. Tyre supplier API/feed for stock and prices.
3. Stripe Checkout Sessions.
4. Database such as Supabase/Postgres.
5. Auth for customers, garages, fitters and admin.
6. Email/SMS via Resend and Twilio.
7. Maps/coverage zones via Google Maps.
